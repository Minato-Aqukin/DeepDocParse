# Persistent scope manifests

Control owns the frozen, caller-scoped scope denominator. A scope is directory metadata, not a historical full-text snapshot. Actual retrieval receipts must record the index revision and evidence versions separately.

`POST /api/v1/federation/scopes` accepts `operation` (required), `member_snapshot_id` (optional; omitted creates a fresh authorized member snapshot), `page_size` (1..100, default 50), `max_members` (1..10000, default 1000), `ttl_seconds` (30..3600, default 900). The caller cannot supply targets, a completeness claim, a caller hash, or source revisions. Creation consumes the existing stable member snapshot through its terminal cursor; partial input, expiry, missing collection catalogs, unsupported child enumeration and budget termination remain visible. A target is `(origin_node_id, collection_id, operation)`; unknown capabilities cannot remove targets. This operation performs metadata enumeration only and sends no user question.

The response is `{manifest,first_cursor,terminal_cursor,total_targets,content_snapshot:"not_frozen",expired,effective_enumeration_state}`. `manifest` follows DDP ScopeManifest. `total_targets` counts only known unique targets; a partial enumeration is not a full denominator and cannot supply a coverage percentage. The digest omits `manifest_digest` and uses compact UTF-8 Go JSON escaping and RFC3339Nano times in wire field order: `schema,scope_id,caller_scope_hash,created_at,valid_until,registry_revision_vector,child_manifests,expanded_members,node_routes,unexpanded_subtrees,enumeration_state`. Targets, child manifests, routes and unknown subtrees are normalized before hashing. `child_manifests` and `node_routes` are omitted when empty. Routes sort by node id and choose the shortest intermediate sequence, then lexical node ids; direct routes win and are not listed. The digest freezes original metadata independently of later authorization overlays. Directory revisions distinguish actual members/collections snapshots; child reports use `directory_ref: subtree:<reporter>:<original directory_ref>` (nested prefixes preserve each reporter). Scope validity is bounded by all observed source snapshots.

`GET /api/v1/federation/scopes/{scope_id}` returns the persisted envelope after checking the current authenticated credential and permission hash. `GET .../{scope_id}/targets?cursor=...` returns `{scope_id,manifest_digest,targets:[{target_key,state}],next_cursor,complete,total_targets,expired}`. Pages and random cursors survive process restart. The terminal cursor returns an empty, complete page; a full nonterminal page is not a completeness proof. State is initially `not_attempted`; source membership or visibility revocation yields `revoked` without deleting the original target or changing its denominator/digest. Local reads revalidate the original corpus catalog snapshot through its terminal cursor. Its identified revoked collections are persistently marked `revoked`; other targets in the now-invalid catalog are `unreachable` until a new scope is made. Changed, expired or unavailable catalog responses cannot imply revocation or successful retrieval. A later successful response cannot resurrect a revoked snapshot. New access must recheck resource authority as well as scope membership.

Expired scopes remain readable as retained history with `expired:true`; their frozen manifest/digest remains unchanged and `effective_enumeration_state` is `expired`. They cannot authorize fresh work. Creating a scope from an already expired member snapshot returns 410 before contacting the catalog producer. Expiry during creation or an interrupted member snapshot preserves observed metadata as `partial` with an unknown subtree; it never joins a newer snapshot to complete the old one. Unknown scope/cursor/credential returns the same 404. Reads use `Cache-Control: no-store`.

递归目录展开保持网状直接读取：可直接联系且本地批准的成员仍直接拉 members／collections。P 公布的成员 R 不能被 A 直接联系时，A 只读一次 P 的 `/subtree` 快照（全部页），将目标路由前缀加上 P；S 只登记于 R 时得到 `[P,R]`。`node_routes: [{node_id,via_node_ids}]` 只列不能直接到达的来源，路由不含根与叶。目标按 `(origin_node_id,collection_id,operation)` 去重；最短路、再节点 id 字典序决定唯一来源路由。P 回报的修订和未知子域可见地并入清单，报告来源由 `directory_ref` 与 child manifest 快照引用标识，不能当成 A 亲自观察。`scope_remote_sources` 保存路由的批准第一跳，撤销 P 即撤销通过 P 取得的整棵子树，不改冻结分母与摘要；另有本地直接授权的来源仍依其当前权限判断。

`max_discovery_requests`（默认64，0..10000）与 `max_remote_members`（默认32，0..10000）是根预算：物理分页请求与子树报告的实际消耗都计入。根把扣除自身请求后的剩余额度传给 P，不给每个层级重置预算。报告超出份额则作废并标 `budget_exhausted`；恰好耗尽但未取得终止页也保持 partial，已见目标不丢。`allowed_node_ids` 接收方边界逐级传递， excluded 节点不得收到目录请求。Control 只存范围与路由元数据，通过 API 读取 corpus 目录；集合内容和执行授权仍属于 corpus，不能凭注册或目录报告宣称检索完成。
