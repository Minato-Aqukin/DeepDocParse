## 推荐使用

1. 先播放 `02-无配音视频/DeepDocParse-带字幕待配音.mp4`，熟悉切页与指图节奏。
2. 对照 `03-配音文稿与字幕/DeepDocParse-配音稿.pdf` 录音；也可按20页分段录制，依据配音时间表放到对应位置。
3. 如果录音与现有节奏一致，直接给带字幕版添加人声即可。
4. 如果停顿或语速不同，使用**无字幕待配音母版 + SRT**，按真实声音微调字幕；需延长某页时，可用04目录对应PNG画面调整该段，整体保持比赛时长要求。

## 配音建议

- 推荐逐页录音；每段可以单独重录，不必一次读完。
- 只读正文，不读页标题、时间码、图里的全部字段名。
- 技术图的角标已按陈述安排，不需要再加入鼠标点击或人工指图。
- 录音后完整播放一次，检查声画对应、字幕、结尾；最终输出仍保持16:9，MP4不超过6分钟和300MB。
- 两版视频没有音轨是有意设置，不是音频丢失。当前交付的是待配音画面，不是已经包含成员陈述的最终参赛视频。

提交时分别选择01中的PPT和加入成员声音后的MP4，不要把整份仓库目录当作匿名附件上传。文件命名、有效入口与评审账号按06中的要求单独办理。原始评审适用于去页脚前的同内容主稿，不将其分数冒用为新版视频的评审结果。
