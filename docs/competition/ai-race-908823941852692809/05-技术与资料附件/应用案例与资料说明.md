## 3. 结构化字段

**实际模板说明**

> 只抽取固定版本原文明确支持的数值，区分模型输入上限、无监督语料语言数和跨语言对应关系数；结果保留出处与未核验状态。

**原任务保存的Schema**

```json
{
  "type": "object",
  "properties": {
    "max_input_tokens": {
      "type": "integer",
      "description": "论文所述模型能处理的最大输入 token 数量；不是批量大小、训练步数或维度。"
    },
    "unsupervised_language_count": {
      "type": "integer",
      "description": "数据整理章节所述无监督语料覆盖的语言数；与摘要宣称模型支持多少语言区分。"
    },
    "cross_lingual_correspondences": {
      "type": "integer",
      "description": "同一无监督语料的跨语言对应关系数；不是语言数量或样本总数。"
    }
  },
  "required": [
    "max_input_tokens",
    "unsupervised_language_count",
    "cross_lingual_correspondences"
  ]
}
```

|字段|保存值|保存状态|
|---|---:|---|
|输入上限 token|8192|found；verified=false|
|无监督语料语言数|194|found；verified=false|
|跨语言对应数|2655|found；verified=false|

语言数与对应数见物理PDF第3页相邻原文，必要局部为`E18-194原文必要局部.png`。8192的主引用是第14页训练段，自己的上下文引用另含第2、9页容量说明，应读完整引用组。界面百分数为检索相关度，不是正确率。完整保存字段见`public-fields-current.jpg`；原失败任务保留在既有工作记录，不将后续成功改写为第一次结果。

## 6. 其他资料与组件

历史技术文献回归含Pico、ESP32、Attention等固定资料；不在本包再分发这些评测PDF。QASPER提供外部人类参考问答，24题首测的Answer F1与Evidence F1分别解释，不能当成同一准确率。完整统计见`项目技术说明与资料来源.pdf`及`材料引用数据摘录.json`。

DeepDocParse复用MinerU等解析器、兼容推理模型、Vue/Electron、FastAPI、PostgreSQL/pgvector、SQLite/FTS、MinIO与Redis/ARQ等组件。项目贡献是处理契约、证据与版本生命周期、任务一致性、双端适配和受控联邦链；基础模型与标准数据库算法不计作本项目原创训练成果。实际模型能力及运行档位以对应记录为准。
