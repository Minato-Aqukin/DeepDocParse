## 本机跑不了的（与合仓前一样）

- mineru pipeline / VQA 平面 / TEI 加速 —— 都要 GPU
- 因此：真实用户路径、检索质量数字、视觉核对阈值重标定，都要等 GPU 机器
- 对象存储对账要一份有数据的 MinIO

## 下一步的确定顺序

1. 在有 docker 的机器上 `scripts/dev.sh up` 起全栈，跑通注册 → 直传 →
   解析 → 索引 → 提问 → 出处 的真实路径（无 GPU 用 borndigital 引擎）
2. 补对象存储对账（迁移器加 `--object-endpoint`）
3. 把 CI 工作流在 GitHub 上真跑一次（本地绿不等于 CI 绿：
   CI 是干净装一遍，会暴露依赖声明的问题）
4. 压测 —— 但**容量目标要先由用户确认**（§12.3、§18 第 5 条）
5. 删除 `docs/refactor/_rewrite-ref-*.py`
6. 旧账号表的删除迁移
